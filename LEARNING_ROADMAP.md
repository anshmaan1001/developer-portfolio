# Learning Roadmap — Ansh Maan

A flexible six-semester plan for building strong foundations in computer science, Artificial Intelligence, and Data Science. Topics may be adjusted according to my university syllabus and learning progress.

## Semester 1 — Programming Foundations
- Learn Python syntax, variables, data types, conditions, loops, and functions.
- Practise problem solving and basic algorithms.
- Understand computer fundamentals and command-line basics.
- Learn Git, GitHub, and Markdown.
- Complete introductory lab assignments.

## Semester 2 — Core Computer Science
- Strengthen object-oriented programming concepts.
- Study data structures and basic algorithms.
- Practise SQL and relational database fundamentals.
- Improve Linux and shell scripting skills.
- Build small command-line projects.

## Semester 3 — Data and Web Foundations
- Learn web fundamentals: HTML, CSS, and JavaScript.
- Work with Python libraries for data handling.
- Study database design and API basics.
- Practise data cleaning and exploratory data analysis.
- Publish well-documented projects on GitHub.

## Semester 4 — Artificial Intelligence and Data Science
- Study statistics and probability for data analysis.
- Learn NumPy, Pandas, and data visualisation.
- Understand machine-learning fundamentals.
- Practise feature engineering and model evaluation.
- Complete an end-to-end beginner ML project.

## Semester 5 — Applied Learning
- Explore intermediate machine-learning methods.
- Learn model deployment and reproducible workflows.
- Explore deep-learning fundamentals.
- Contribute to a team or open-source project.
- Build a larger project with clear documentation.

## Semester 6 — Portfolio and Career Preparation
- Complete and document a capstone project.
- Review core programming, data structures, and ML concepts.
- Improve project testing, code quality, and documentation.
- Prepare a technical resume and interview portfolio.
- Explore internship and entry-level opportunities.

## Review

I will update this roadmap as my interests, coursework, and skills develop.
